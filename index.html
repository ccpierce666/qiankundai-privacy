一、适用范围

本政策适用于《乾坤袋乱斗》Android 游戏本体，以及与该游戏有关的隐私咨询和问题反馈。当前游戏为本地单机背包构筑游戏，不要求注册开发者自有账号。

您通过 TapTap 下载游戏或使用平台服务时，平台提供的账号、实名认证、防沉迷、分发和运行服务另受平台向您展示的协议与隐私政策约束。本政策不替代第三方平台对其自身信息处理活动的说明。

二、我们如何处理信息

1. Android ID

信息名称Android ID（Android 系统为设备或应用环境提供的标识符）
获取主体APP 自身
获取时机用户点击隐私政策弹窗中的“同意”后
获取方式通过 Android 系统接口自动获取
获取目的用于识别设备或应用实例、保障游戏运行安全、排查运行异常，以及避免本地存档数据混淆
处理方式仅用于上述运行与安全目的，不用于广告画像或营销；当前不会上传至开发者服务器，也不会向第三方共享

2. 本地游戏数据与设置

在您同意隐私政策后，游戏会在设备的应用存储空间保存音量、静音状态、所选流派、乾坤袋格子、道具位置、战斗记录和构筑阵容，用于恢复设置、展示历史战绩和提供后续对战。当前游戏业务代码不将这些本地数据上传至开发者服务器。

3. 您主动提供的反馈

当您通过邮件联系我们时，我们会处理您主动提供的邮件地址、邮件内容，以及您选择附带的设备型号、系统版本、问题描述、截图或日志，用于回复咨询、处理故障或办理个人信息请求。提交前请删除与问题无关的个人信息，请勿发送密码、验证码或身份证照片等不必要的敏感信息。

4. 当前未提供的信息处理功能

当前游戏本体未提供开发者账号注册、广告投放、内购支付或社交通讯功能；未设置读取通讯录、短信、精确位置、麦克风、摄像头或共享存储的业务功能，也不通过游戏业务代码获取 IMEI、IMSI 或广告标识符用于用户画像和营销。

三、设备权限与本地存储

当前 Android 游戏本体未声明摄像头、麦克风、定位、通讯录、短信或共享存储读写权限。本地设置和战斗记录保存在应用自身存储空间，不需要访问您的相册、通讯录或其他应用文件。

游戏引擎会使用屏幕尺寸、图形能力、触控输入和音频输出等运行环境信息，以完成画面适配、音频播放和交互。该运行信息不会通过当前游戏业务功能上传至开发者服务器。

您可以通过系统设置清除应用数据或卸载游戏，以删除本地设置、战斗记录、同意记录和其他本地数据。清除后再次启动时，应用会重新展示隐私政策弹窗。

四、游戏引擎与第三方服务

1. Godot 游戏引擎

游戏使用开源 Godot 引擎实现画面、音频、输入和本地存储。当前项目未接入广告、统计分析或崩溃自动上报 SDK，也未建立开发者数据上传服务器。

Godot 相关说明：Godot 隐私政策。

您使用 TapTap 下载、安装或运行游戏时，平台可能为账号管理、分发、安全保障、实名认证和防沉迷处理相应的账号、设备、网络及使用信息。具体信息种类、用途、保存期限和权利行使方式，请以平台当时向您展示的说明为准。

平台隐私说明：TapTap 隐私政策。

五、共享、转让与公开披露

我们不出售您的个人信息，不将 Android ID、本地游戏数据或隐私咨询内容用于广告营销。除取得您的单独同意、为处理您主动提出的请求所必需，或法律法规另有规定外，我们不会向其他主体提供、转让或公开披露您的个人信息。

如未来接入新的第三方 SDK 或在线服务，我们会先更新本政策，说明处理主体、信息类型、目的和方式，并在依法需要时重新取得您的同意。

六、信息保存与安全保护

Android ID 仅在应用运行所需范围内处理；本地设置和战斗记录保存在您的设备中，直至被覆盖、通过系统清除或随游戏卸载删除。当前游戏业务功能不主动向境外传输这些信息。

您主动发送的联系信息会保存在用于处理咨询的邮箱等必要工作环境中，仅在回复、解决问题和处理相关争议所必需的期间内保存；目的完成且不再需要保留时，我们会删除或匿名化处理，法律法规另有要求的除外。

我们会采取与信息处理相适应的访问限制、账号安全和最小必要处理措施。如发生个人信息安全事件，我们将依法采取补救措施，并在需要时通知受影响用户及有关主管部门。

七、您的权利

  • 选择同意或拒绝：首次启动时您可以在弹窗中明确选择。拒绝后应用退出，不进入游戏。
  • 撤回同意：您可以通过系统设置清除应用数据或卸载游戏；清除后本地同意记录失效。您也可以通过下方邮箱联系我们。
  • 查阅、更正、删除：您可以联系我们，请求处理您曾通过邮件主动提供的反馈和联系信息。
  • 管理本地数据：您可以在游戏中调整音频设置，或通过系统入口清除游戏数据。
  • 账号注销：当前游戏本体没有开发者自有账号。TapTap 账号的注销请通过 TapTap 平台办理。
  • 咨询和投诉：对本政策或处理方式有疑问时，您可以向我们咨询，也可以依法向有关主管部门投诉。

我们可能要求您提供与请求相匹配的必要信息，以核实请求与您的关联，避免他人冒用。我们会在收到请求后 15 个工作日内回复处理情况；依法不能满足请求的，将说明理由。

八、未成年人保护

未成年人应在监护人的指导下阅读本政策并合理使用游戏。不满十四周岁的未成年人向我们提供个人信息前，应取得监护人的同意。游戏本体不会主动要求儿童提供姓名、身份证号码或人脸信息。

如监护人发现未成年人未经同意向我们提交了个人信息，可通过联系邮箱要求核实和删除。使用 TapTap 时，请同时遵守平台的实名认证、防沉迷和监护人管理要求。

九、政策更新

当游戏功能或信息处理方式发生变化时，我们会更新本政策及更新日期。涉及处理目的、信息类型、第三方服务或您权利的重大变化时，我们会在应用启动时重新展示弹窗，并在依法需要时重新取得您的同意。
